# 鸣潮声骸助手

按角色方案自动刷声骸、升级，并在每次调谐后判断该继续升级、上锁还是打废弃标记，避免把资源浪费在注定不毕业的声骸上。

运行在 [ok-wuthering-waves](https://github.com/ok-oldking/ok-wuthering-waves)（ok-ww）之上：刷本战斗、体力、背包和强化界面操作复用 ok-ww，本项目负责角色方案、判断逻辑和桌面软件。只通过截图识别和模拟键鼠操作游戏，不读内存、不改游戏文件。

> 使用第三方自动化工具违反《鸣潮》用户协议，有封号风险，请自行承担。

## 功能

- **浅色桌面软件**：角色卡片、彩色词条标签（红 = 必要，蓝 = 选要，灰 = 无效）、开关和大的开始按钮。ok-ww 在后台运行，不弹出它自己的窗口。
- **角色方案**：每个角色一份，包含套装、刷取方式、C4/C3/C1 主词条（可多选）、必要和选要副词条、喂料方式。
- **刷取**
  - C1/C3：刷指定无音区。可选“只用当日体力”或“当日体力 + 储存的结晶一起用完”。体力用完后统一升级。
  - C4：反复打指定 Boss。每 10 轮去背包数一次，攒够 30 个目标套装的 0 级 C4 再去升级。刷满最多轮数还不够就停下。
- **升级与判断**：逐个升级背包里 0 级的目标声骸，每调谐出一条副词条就判断一次。
- **毕业上限**：本次毕业满 2 个就暂停并询问。选继续，做到 4 个毕业后结束。

## 判断规则

必要词条：没有就算废；选要词条：不是必须，有更好；有效词条 = 必要 + 选要。

| 阶段 | 条件 | 结果 |
|---|---|---|
| 任何一步 | 还缺的必要词条数 > 剩余槽数 | 废弃 |
| 0 级 | 主词条不在所选范围 | 废弃，不花资源 |
| 第 1~2 条 | — | 继续 |
| 第 3 条后 | 必要 ≥ 1 且 有效 ≥ 2 | 继续，否则废弃 |
| 第 4 条 | 必要 | 继续 |
| | 选要 | 继续；前三条为 1 必要 1 选要且该必要是最低 1 档时废弃 |
| | 无效 | 前三条已三有效才继续，否则废弃 |
| 第 5 条后 | 必要词条全部都有 且 有效 ≥ 3 | 上锁 |
| | 否则 | 废弃 |

副词条档位表见 `echo_helper/stats.py`。

## 使用

桌面上的 **声骸助手** 快捷方式会以管理员身份启动（ok-ww 操作游戏需要管理员权限）。第一次双击会弹出用户账户控制提示，点“是”。

1. 在软件里选角色，或点“新建角色”填写方案后保存。套装名要和游戏里的合鸣效果一字不差。
2. 进游戏，人站在大世界。背包声骸页先设好筛选：五星 + 该角色套装，排序选“等级”并从低到高。
3. 回到软件，打开“刷取声骸”和“升级声骸”，点“开始”。

开始升级前，脚本会自己把游戏的“自动放入设置”设成：阶段放入、开启同步调谐、方案里选的放入材料，材料品质“不限”，材料列表排序“等级顺序”。对不上就截图并停下。

喂料两种：

- **强化材料和声骸**：没上锁的声骸都能吃。毕业声骸会被自动上锁，游戏不会拿上锁的声骸当材料。判废的声骸仍会打上废弃标记，方便在背包里辨认。
- **仅强化材料**：只用密音筒。

## 第一次进游戏要一起看的两件事

1. 材料排序设成“等级顺序”之后，阶段放入是先吃声骸还是先吃密音筒。
2. 品质“不限”会不会把还没处理的 +0 胚子放进材料。放入之后看材料列表里有没有 +0。
